# Intent: 邮件和短信发送渠道与模板配置优化
Author: Rain Wang. Status: accepted.

## Problem
平台管理员目前缺少一套与目标管理体验一致、边界明确的消息设置能力，无法在同一入口清晰地浏览和维护邮件模板、启停邮件与短信服务，并按受支持的服务提供商完成渠道配置。邮件和短信场景模板、渠道凭据及启停状态若缺乏统一管理，会增加身份验证类消息配置和运维的成本，并带来配置错误、敏感信息暴露或消息无法送达的风险。

## Proposed outcome
平台管理员可以在平台全局的“消息设置”中分别管理邮件模板、邮件服务和短信服务：浏览邮件模板效果，选择使用系统默认邮件或按场景自定义邮件内容；启停邮件服务，并配置自定义 SMTP、阿里云企业邮、腾讯云企业邮或网易企业邮；启停短信服务，并配置阿里云或腾讯云短信及各发送场景对应的模板标识。关闭自定义邮件时使用系统默认模板，关闭某个发送服务时不再通过该渠道发送消息；七牛云短信不再作为可选服务商。保存后的有效配置接入真实业务发送链路，邮件模板浏览和短信测试发送均可正常使用。

## Affected users and systems
受影响用户是拥有现有系统设置权限的平台管理员，以及接收绑定、登录验证、密码操作、欢迎通知和密码到期提醒等身份类消息的终端用户。受影响系统包括 Macula Cloud 管理端、System 服务及其 API/持久化、IAM 身份流程中的邮件和短信真实发送链路，以及现有邮件和短信服务商集成。

## Constraints
保持 Java 17、Spring Boot 4.0、Spring Cloud 2025.1、Vue 3/Vite 及现有平台协议兼容；设置范围为平台全局，不增加独立权限，沿用现有系统设置权限并维持清晰的权限边界；渠道密码、AccessKey、SecretKey 等敏感凭据不得明文回显或写入仓库配置；邮件支持自定义 SMTP、阿里云企业邮、腾讯云企业邮和网易企业邮，短信支持阿里云和腾讯云并排除七牛云；邮件完整场景为绑定邮箱、修改绑定邮箱、忘记密码、修改密码、管理员重置密码成功、登录验证、密码到期提醒和欢迎邮件；短信完整场景为绑定手机号、绑定成功、修改手机号、忘记密码、修改密码、管理员重置密码成功、登录验证、欢迎短信和密码到期提醒；交互与任务截图保持一致，邮件模板浏览和短信测试发送属于验收范围；本次不要求迁移或兼容现有配置数据；配置、远程契约、持久化结构和调用链变化需要同步更新调用方、说明和测试；无额外交付期限、审计要求或合规限制。
