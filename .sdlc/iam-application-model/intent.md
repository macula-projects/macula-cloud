# Intent: IAM接入应用领域模型统一
Status: accepted

2026-11-12用户ok接受统一IAM接入应用命名及内部application_id关联，随后明确要求考虑三表内容以支持未来SAML2/CAS，并回答“保持单选协议，支持更多协议类型”。本接受记录仅对应目标和协议单选决策，新的字段分层、统一来源关联及迁移规格仍需审阅。

目标：应用模型与OAuth2解耦，区分用户登录认证和下游协议发布；统一命名、内部关联及协议配置权威来源，保留当前全部功能、客户端标识、凭据、用户绑定和安全边界。单个应用最多选择一种协议，不实现同应用多协议并存。未来可增加SAML2/CAS，当前不宣称已实现其协议引擎。

授权范围：准备代码及可验证迁移方案，完成验证；未授权升级运行数据库、重建部署镜像、提交、推送或合并。
