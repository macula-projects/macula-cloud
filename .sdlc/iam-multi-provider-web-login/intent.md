# Intent: IAM 多平台网页认证接入
Author: Rain. Status: accepted.

## Problem
业务员目前无法在飞书、钉钉、微信和支付宝相关业务场景中，统一使用对应平台身份完成 IAM 网页登录；普通浏览器授权登录和平台客户端内网页免登尚未完整接入，业务员仍需改用其他登录方式。

## Proposed outcome
业务员可以在普通浏览器中选择飞书、钉钉、微信或支付宝完成授权登录，也可以在相应平台客户端内打开 IAM 网页时使用平台身份免登。登录结果应进入现有 IAM 认证闭环，并能被业务页面正常使用。

## Affected users and systems
受影响用户为业务员。受影响系统包括 Macula Cloud IAM、身份源配置管理、登录页面，以及飞书、钉钉、微信和支付宝的认证开放能力。

## Constraints
四个平台均须覆盖普通浏览器授权登录和对应客户端内网页免登；本期不考虑任何小程序登录。不得削弱现有认证安全边界，也不得在日志、页面或持久化数据中泄露平台凭据、授权码或令牌。

## Open questions
无。各平台具体协议、开放能力限制和配置要求在设计阶段核对，但不得缩减上述用户场景。
