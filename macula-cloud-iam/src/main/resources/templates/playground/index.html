    如何理解结果
    Access Token ≠ ID Token
    本演示访问令牌为 opaque，不能当 JWT 解码。ID Token 是 JWT，必须验签并校验绑定后才代表登录结果。
    
        
    ID Token：尚未验证
    “仅解码”不等于验证通过。本页只有服务端完成验签与 claims 校验后才显示已验证。
    
        
    失败时检查什么？
    invalid_client：注册/secret/认证方式；invalid_grant：过期、重放或 PKCE；invalid_scope：超出许可；access_denied：用户拒绝或授权失效。网络失败先检查 issuer 的双向可达性。
